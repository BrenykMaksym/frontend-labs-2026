# Світлофор

Наскрізний React/Vite-проєкт із вебпрограмування.

```sh
npm ci
npm run dev
```

Для перевірки збірки використайте `npm run build`.

## ЛР1 · CP1

`App` показує два екземпляри `TrafficLights`. Орієнтація передається через props. `TrafficLights` компонує три компоненти `Light`, кожен із яких отримує колір через props. Стилі компонування спільні для обох орієнтацій.

## ЛР2 · CP2

Обирайте сигнал натисканням, зокрема повторно для того самого кольору. Власник стану передає дані й обробник через props. StatsBar обчислює суму з лічильників. Зміна орієнтації зберігає поточний сигнал і статистику.

## ЛР3 · CP3

«Запустити» починає цикл із червоного сигналу. Порядок фаз: червоний → жовтий → зелений → жовтий → червоний. Індекс фази розрізняє два жовті сигнали й визначає один таймер у useEffect. Ефект очищає його під час зміни фази, зупинки чи демонтажу. «Зупинити» залишає поточний сигнал і повертає ручне керування. Таймер не змінює лічильники.

## ЛР4 · CP4

Маршрути — головна (/), керування (/traffic-light), статистика (/stats) та сторінка для невідомих адрес. TrafficLightsProvider змонтований над Routes, тому зміна маршруту не перезапускає таймер і не скидає стан. Для статичного хостингу налаштуйте перенаправлення маршрутів на index.html.

## Контрольні точки

Кожна ЛР має окремий коміт і тег від cp1 до cp4. Для перегляду конкретної версії виконайте git switch --detach cp1, замінивши cp1 потрібним тегом, потім npm ci і npm run dev. Щоб повернутися до останньої версії, виконайте git switch main.

## ЛР5 · CP5

У застосунку поточний сигнал і збережений у Google Таблицях сигнал показано окремо. Початковий GET читає запис main і відновлює сигнал. Кнопка «Зберегти поточний сигнал» робить POST і показує підтверджене сервером значення. Автоматичний цикл змінює лише локальний стан.

1. Створіть аркуш TRAFFIC_LIGHTS із заголовками id та current_signal і рядком main | red.
2. Додайте gas/Code.gs до Apps Script і встановіть у властивостях скрипта DB_SPREADSHEET_ID зі значенням ID таблиці.
3. Розгорніть версію вебзастосунку з виконанням від імені власника й доступом «Усі». За адресою API можна читати й змінювати сигнали навчальної таблиці.
4. Скопіюйте .env.example у .env.local і впишіть адресу /exec у VITE_TRAFFIC_LIGHTS_API_URL. Запустіть npm run dev.
5. На /traffic-light виберіть інший сигнал, збережіть його, перевірте B2 і перезавантажте сторінку. Після GET відобразиться збережений колір.
